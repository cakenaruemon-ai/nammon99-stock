# น้ำมนต์ 99 Stock — v2

แอปจัดการสต๊อกรถ การขาย มัดจำ และติดตามเงินดาวน์ ใช้บนมือถือได้เหมือนแอปทั่วไป (ติดตั้งลงหน้าจอโฮมได้)

## อัปเดตจาก v1 เป็น v2 (ทำตามลำดับ)

1. **อัปเดตฐานข้อมูล:** เปิด Supabase > SQL Editor > New query แล้ววางไฟล์ `supabase_schema.sql` ทั้งไฟล์ กด Run
   - รันซ้ำได้ ไม่ลบข้อมูลเดิม
   - รถที่มีสถานะเดิมแบบอื่น (รอตรวจสภาพ / กำลังซ่อม / จองแล้ว / ยกเลิก ฯลฯ) จะถูกเปลี่ยนเป็น "พร้อมขาย"
2. **อัปโหลดไฟล์ขึ้น GitHub** (แทนที่ไฟล์เดิมทั้งหมด):
   `index.html`, `sw.js`, `manifest.webmanifest`, `supabase_schema.sql`, `README_TH.md` และโฟลเดอร์ `icons/`
   - `config.js` ใช้ไฟล์เดิมได้เลย ไม่ต้องแก้
3. รอ GitHub Pages อัปเดตประมาณ 1–2 นาที แล้วเปิดแอปใหม่

## ติดตั้งเป็นแอปบนมือถือ

- **Android (Chrome):** เปิดลิงก์แอป แล้วกดปุ่ม "ติดตั้ง" ที่แถบสีดำบนหน้าสต๊อก หรือเมนู ⋮ > "ติดตั้งแอป"
- **iPhone / iPad (Safari):** กดปุ่มแชร์ > "เพิ่มไปยังหน้าจอโฮม"
- เมื่ออัปโหลดเวอร์ชันใหม่ แอปที่ติดตั้งไว้จะได้เวอร์ชันล่าสุดเองเมื่อเปิดครั้งถัดไป

> แอปต้องเปิดผ่าน https (GitHub Pages เป็น https อยู่แล้ว) จึงจะติดตั้งได้ ถ้าเปิดไฟล์จากเครื่องโดยตรงจะติดตั้งไม่ได้

## ฟังก์ชันใน v2

- สต๊อกรถ: ค้นหา, ต้นทุน + กำไรคาด, อายุสต๊อก, เตือนรถค้างเกิน 90 วัน
- เพิ่มรถแบบพิมพ์/พูดรวดเดียว, ฟอร์มเต็ม, ตรวจทะเบียนซ้ำ
- ค่าใช้จ่ายแยกประเภท (ลบรายการผิดได้), ราคากลาง TTB / Tisco + ประวัติ
- สถานะรถ 2 แบบ: พร้อมขาย / ขายแล้ว
- รับมัดจำ / จองรถ: นัดรับรถ, วันหมดจอง, เงื่อนไขคืนมัดจำ, หักมัดจำอัตโนมัติตอนขาย
- บันทึกการขาย: เงินสด / ไฟแนนซ์ (TTB, Tisco, กรุงศรี, เกียรตินาคินภัทร, อื่น ๆ), เงินดาวน์, ยอดจัด, ค่าคอม, ข้อมูลลูกค้า + ช่องทางติดต่อ
- ประวัติการขาย: สรุปรายเดือน, กำไรจริง, สัดส่วนช่องทางชำระ, ค้นหาลูกค้า
- ลูกค้าค้างดาวน์: ตารางนัดจ่าย, รับชำระ, เลื่อนนัด, บันทึกการติดตาม + ประวัติ, ส่งสรุปยอดค้างทาง LINE
- ภาพรวม: ทุนในสต๊อก, กำไร, อายุสต๊อก, รายการ "ต้องจัดการ"
- ดาวน์โหลดสต๊อก / ประวัติการขาย เป็นไฟล์ CSV (เปิดใน Excel ได้)
- ซิงก์อัตโนมัติ: แก้ไขจากเครื่องหนึ่ง เครื่องอื่นเห็นทันที

## ตั้งค่าโปรเจ็คใหม่ (ครั้งแรก)

1. สร้าง project ใน Supabase แล้วรัน `supabase_schema.sql`
2. Project Settings > API: คัดลอก Project URL และ publishable (anon) key ใส่ใน `config.js`
3. Authentication > Providers: เปิด Email และปิดการสมัครเอง (Disable new user signups)
4. Authentication > Users: สร้างบัญชีพนักงาน แล้วเพิ่มลงตาราง `employees` ตามตัวอย่างท้ายไฟล์ SQL

## ความปลอดภัย

- ใน `config.js` ใส่ได้เฉพาะ publishable/anon key ห้ามใส่ service_role / secret key
- ทุกตารางเปิด Row Level Security: เฉพาะพนักงานที่ active ใน `employees` เท่านั้นที่อ่าน/แก้ข้อมูลได้
- แนะนำให้เปิด 2FA กับบัญชี Supabase และ GitHub
